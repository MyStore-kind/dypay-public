# 国际四方支付系统技术改造方案

## 一、改造策略

### 1.1 改造原则
- **非侵入式扩展**：不修改 JeePay 核心代码，通过继承和扩展实现新功能
- **模块化设计**：新增功能独立模块，便于维护和升级
- **向后兼容**：保留 JeePay 原有功能，支持国内支付通道
- **渐进式迭代**：分阶段实施，每个阶段可独立上线

### 1.2 技术栈保持
- **后端框架**：Spring Boot 3.3.7 + JDK 17
- **ORM 框架**：MyBatis-Plus 3.5.7
- **数据库**：MySQL 8.0 + Redis
- **消息队列**：RocketMQ（保持 JeePay 配置）
- **前端**：Ant Design Vue 4.2.6

## 四、核心功能实现

### 4.1 多币种支持

#### 4.1.1 币种转换服务
```java
@Service
public class CurrencyRateService {
    
    /**
     * 获取实时汇率
     * @param baseCurrency 基准币种
     * @param targetCurrency 目标币种
     * @return 汇率
     */
    public BigDecimal getRealTimeRate(String baseCurrency, String targetCurrency) {
        // 1. 优先从缓存获取
        // 2. 缓存未命中则从数据库获取最新汇率
        // 3. 数据库无数据则调用第三方API
        // 4. 更新缓存和数据库
    }
    
    /**
     * 金额换算
     * @param amount 原始金额（单位：分）
     * @param fromCurrency 原币种
     * @param toCurrency 目标币种
     * @return 换算后金额（单位：分）
     */
    public Long convertAmount(Long amount, String fromCurrency, String toCurrency) {
        if (fromCurrency.equals(toCurrency)) {
            return amount;
        }
        BigDecimal rate = getRealTimeRate(fromCurrency, toCurrency);
        return new BigDecimal(amount).multiply(rate).longValue();
    }
}
```

#### 4.1.2 订单创建时记录汇率
```java
@Service
public class PayOrderService {
    
    @Autowired
    private CurrencyRateService currencyRateService;
    
    public PayOrder createPayOrder(PayOrderCreateRequest request) {
        PayOrder order = new PayOrder();
        
        // 设置订单币种
        order.setCurrency(request.getCurrency());
        order.setAmount(request.getAmount());
        
        // 获取商户结算币种
        MchInfo mchInfo = mchInfoService.getById(request.getMchNo());
        String settlementCurrency = mchInfo.getSettlementCurrency();
        
        // 如果订单币种与结算币种不同，记录汇率并计算结算金额
        if (!order.getCurrency().equals(settlementCurrency)) {
            BigDecimal rate = currencyRateService.getRealTimeRate(
                order.getCurrency(), settlementCurrency
            );
            order.setExchangeRate(rate);
            order.setSettlementCurrency(settlementCurrency);
            order.setSettlementAmount(
                currencyRateService.convertAmount(
                    order.getAmount(), 
                    order.getCurrency(), 
                    settlementCurrency
                )
            );
        } else {
            order.setSettlementCurrency(settlementCurrency);
            order.setSettlementAmount(order.getAmount());
        }
        
        // 保存订单
        save(order);
        return order;
    }
}
```

### 4.2 代理商分润

#### 4.2.1 分润计算服务
```java
@Service
public class AgentProfitService {
    
    /**
     * 计算并记录代理商分润
     * @param payOrder 支付订单
     */
    @Transactional
    public void calculateAndRecordProfit(PayOrder payOrder) {
        // 1. 获取商户所属代理商
        MchInfo mchInfo = mchInfoService.getById(payOrder.getMchNo());
        if (StringUtils.isBlank(mchInfo.getAgentNo())) {
            return; // 无代理商，不分润
        }
        
        // 2. 递归计算各级代理商分润
        String currentAgentNo = mchInfo.getAgentNo();
        while (StringUtils.isNotBlank(currentAgentNo)) {
            AgentInfo agent = agentInfoService.getById(currentAgentNo);
            
            // 计算分润金额
            Long profitAmount = calculateProfitAmount(
                payOrder.getSettlementAmount(), 
                agent.getProfitRate()
            );
            
            // 记录分润
            AgentProfitRecord record = new AgentProfitRecord();
            record.setAgentNo(agent.getAgentNo());
            record.setMchNo(payOrder.getMchNo());
            record.setPayOrderId(payOrder.getPayOrderId());
            record.setOrderAmount(payOrder.getAmount());
            record.setOrderCurrency(payOrder.getCurrency());
            record.setProfitAmount(profitAmount);
            record.setProfitCurrency(payOrder.getSettlementCurrency());
            record.setProfitRate(agent.getProfitRate());
            record.setState((byte) 0); // 待结算
            
            agentProfitRecordMapper.insert(record);
            
            // 继续处理上级代理商
            currentAgentNo = agent.getParentAgentNo();
        }
    }
    
    /**
     * 计算分润金额
     */
    private Long calculateProfitAmount(Long orderAmount, BigDecimal profitRate) {
        return new BigDecimal(orderAmount)
            .multiply(profitRate)
            .divide(new BigDecimal(100), 0, RoundingMode.DOWN)
            .longValue();
    }
}
```

@Service
public class StripePaymentService extends AbstractPaymentService {
    
    @Override
    public String getIfCode() {
        return "stripe";
    }
    
    @Override
    public ChannelRetMsg pay(PayOrderCreateReqModel model) {
        // 1. 获取 Stripe 配置
        JSONObject stripeConfig = getChannelConfig(model.getMchNo(), model.getAppId());
        String apiKey = stripeConfig.getString("apiKey");
        
        // 2. 初始化 Stripe SDK
        Stripe.apiKey = apiKey;
        
        // 3. 创建 PaymentIntent
        Map<String, Object> params = new HashMap<>();
        params.put("amount", model.getAmount()); // Stripe 金额单位：分
        params.put("currency", model.getCurrency().toLowerCase());
        params.put("payment_method_types", Arrays.asList("card"));
        params.put("metadata", Map.of(
            "mch_order_no", model.getMchOrderNo(),
            "pay_order_id", model.getPayOrderId()
        ));
        
        try {
            PaymentIntent intent = PaymentIntent.create(params);
            
            // 4. 返回结果
            ChannelRetMsg retMsg = new ChannelRetMsg();
            retMsg.setChannelState(ChannelRetMsg.ChannelState.WAITING);
            retMsg.setChannelOrderId(intent.getId());
            retMsg.setPayData(intent.getClientSecret()); // 前端需要的 client_secret
            
            return retMsg;
        } catch (StripeException e) {
            throw new BizException("Stripe 支付失败: " + e.getMessage());
        }
    }

## 八、风险与应对

### 8.1 技术风险
| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 汇率波动导致结算差异 | 高 | 记录下单时汇率，结算时使用历史汇率 |
| Stripe API 限流 | 中 | 实现请求队列和重试机制 |
| 数据库性能瓶颈 | 中 | 订单表分库分表，汇率表使用 Redis 缓存 |

### 8.2 业务风险
| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 代理商分润纠纷 | 高 | 详细记录分润计算过程，提供对账报表 |
| 跨境支付合规问题 | 高 | 接入前咨询法律顾问，申请必要牌照 |
| 汇率损失 | 中 | 设置汇率加点，覆盖汇率波动风险 |
