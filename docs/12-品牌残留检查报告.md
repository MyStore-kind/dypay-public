## 二、内部技术残留（不影响用户视觉，可保留）

### 2.1 ✅ 组件命名 Jeepay* 前缀（建议保留）

dist 打包产物中统计：
- `JeepayCard`（6 次）、`JeepayTable`（34 次）、`JeepayTextUp`（30 次）、`JeepayTableColumns`（20 次）、`JeepayUpload`（4 次）、`JeepayLayout`（多次）等组件名
- **建议保留**：纯代码内部名称，不影响显示。改名风险大，没价值

### 2.2 ✅ Java 包名 `com.jeequan.jeepay.*`（建议保留）

- 25+ 个文件含 `package com.jeequan.jeepay.*`
- **建议保留**：改包名会导致编译失败、Mapper XML namespace 失效、依赖混乱

### 2.3 ✅ Java 源文件注释里的 `@site https://www.jeequan.com`

- 25+ 个 Java 文件头注释
- **建议保留**：仅是代码注释，对外完全不可见

### 2.4 ✅ CSS 类名 `.jeepay-menu / .jeepay-drawer / .jeepay-card-*`

- 多个组件用 jeepay 前缀的 CSS 类
- **建议保留**：纯样式，用户看不到
