# 11 - 宝塔服务器部署手册

> 适用对象：测试环境部署。无需域名与 HTTPS，先用服务器公网 IP 跑通业务流程。
> 适用系统：CentOS 7/8、Ubuntu 20/22、Debian 11/12 + 宝塔面板（任意版本）

---

## 一、上传项目

两种方式任选其一：

**方式 A：宝塔面板**
1. 登录宝塔 → 左侧「文件」 → 进入 `/www/wwwroot/`
2. 点「上传」，把 `my-international-payment` 与 `jeepay-ui` 两个目录整体上传
3. 二者**必须在同一父目录**（compose 中以 `../jeepay-ui/...` 引用）

**方式 B：scp 命令**
```bash
scp -r my-international-payment/ root@<服务器IP>:/www/wwwroot/
scp -r jeepay-ui/             root@<服务器IP>:/www/wwwroot/
```

最终目录结构：
```
/www/wwwroot/
├── my-international-payment/
│   ├── deploy/
│   ├── docker-compose.deploy.yml
│   └── ...
└── jeepay-ui/
    ├── jeepay-ui-manager/
    └── jeepay-ui-merchant/
```

## 二、安装 Docker（已装可跳过）

**方式 A：宝塔面板**
软件商店 → 搜索「Docker管理器」 → 一键安装。

**方式 B：脚本**
```bash
cd /www/wwwroot/my-international-payment
sudo bash deploy/setup-server.sh
```

脚本会自动：
- 识别系统（CentOS / Ubuntu / Debian）
- 安装 Docker（阿里云源）与 docker-compose
- 写入镜像加速配置
- 检测端口占用并输出环境摘要

---

## 三、配置环境变量

```bash
cd /www/wwwroot/my-international-payment
cp deploy/.env.example deploy/.env
vi deploy/.env
```

**必改项**（含 `请改为` 占位符）：
- `MYSQL_ROOT_PASSWORD` —— MySQL root 密码（32 位强随机）
- `MYSQL_USER_PASSWORD` —— 业务用户密码
- `REDIS_PASSWORD` —— Redis 密码
- `JEEPAY_JWT_SECRET` —— JWT 密钥，可执行 `openssl rand -base64 48` 生成
- `STRIPE_API_KEY` / `STRIPE_WEBHOOK_SECRET` —— 先填测试 key（`sk_test_` 开头）
- `PUBLIC_BASE_URL` —— 例：`http://1.2.3.4`

**可选项**：PayPal、Fixer.io、Telegram、SMTP。留空则对应功能不可用，但不影响主链路。

---

## 四、一键部署

```bash
bash deploy/deploy.sh
```

脚本流程：
1. 校验 `.env` 全部必填项
2. 拉取/构建镜像
3. `docker compose up -d`
4. 等待 MySQL 健康
5. 自动调用 `init-database.sh` 顺序执行 5 个 SQL 补丁（幂等）
6. 输出全部访问地址

首次构建会耗时 5-15 分钟（Maven 下依赖 + npm 构建前端）。

---

## 五、初始化数据库（脚本失败时手动执行）

```bash
bash deploy/init-database.sh
```

或宝塔 → phpMyAdmin → 选 `jeepaydb` → 按以下顺序导入：

1. `sql/jeepay-origin/init.sql`
2. `sql/international_payment_patch.sql`
3. `sql/risk_control_patch.sql`
4. `sql/risk_circuit_breaker_patch.sql`
5. `sql/permission_menu_patch.sql`

脚本内部使用 `db_patch_version` 表实现幂等，重复执行不会报错。

## 六、宝塔反向代理（可选，给前端一个统一 80 入口）

1. 宝塔 → 网站 → 添加站点 → 域名填服务器 IP，端口 80
2. 进入站点 → 反向代理 → 添加：

| 名称 | URL | 目标 |
| --- | --- | --- |
| ui-manager | `/manager/` | `http://127.0.0.1:8083` |
| ui-merchant | `/merchant/` | `http://127.0.0.1:8082` |
| payment-api | `/payapi/` | `http://127.0.0.1:9216` |
| manager-api | `/mgrapi/` | `http://127.0.0.1:9217` |
| merchant-api | `/mchapi/` | `http://127.0.0.1:9218` |

> 不做反代时，直接 `http://<IP>:8083` 访问运营后台。

## 七、Stripe / PayPal Webhook 回调配置

### Stripe
1. 登录 https://dashboard.stripe.com/test/webhooks
2. 添加端点（Add endpoint）：
   - URL: `http://<服务器IP>:9216/api/anon/paySpringChannel4Stripe`
   - 订阅事件：`payment_intent.succeeded`、`payment_intent.payment_failed`、`charge.refunded`、`charge.dispute.created`、`charge.dispute.closed`
3. 拷贝 Webhook signing secret（`whsec_...`），填入 `.env` 的 `STRIPE_WEBHOOK_SECRET`，重启 payment：
   ```bash
   docker restart jeepay-payment
   ```

### PayPal
1. https://developer.paypal.com → My Apps → Sandbox App → Webhooks
2. URL: `http://<服务器IP>:9216/api/anon/paySpringChannel4PayPal`
3. 订阅事件：`PAYMENT.CAPTURE.COMPLETED`、`PAYMENT.CAPTURE.REFUNDED`、`CUSTOMER.DISPUTE.CREATED`
4. 复制 Webhook ID 到 `.env` 的 `PAYPAL_WEBHOOK_ID`

## 九、常见故障排查（FAQ）

| 症状 | 排查命令 / 解决 |
| --- | --- |
| MySQL 容器一直 unhealthy | `docker logs jeepay-mysql --tail 200`，常见为密码含特殊字符未转义 |
| manager 启动失败 | `docker logs jeepay-manager --tail 200`，检查 `.env` 的 JWT_SECRET 与 DB URL |
| Stripe Webhook 收 404 | 端点 URL 必须以 `/api/anon/paySpringChannel4Stripe` 结尾，不要加斜杠 |
| Stripe 回调签名校验失败 | `.env` 中 `STRIPE_WEBHOOK_SECRET` 与 Stripe 后台的 signing secret 不一致 |
| 风控误杀正常订单 | 改 `RISK_GRAYSCALE` 降低灰度，或 `RISK_CONTROL_ENABLED=false` 临时关闭 |
| 3DS 卡死无回调 | 检查 Stripe Dashboard 对应 PaymentIntent 状态，查 payment 日志中 `3DS challenge` 关键字 |
| RocketMQ broker 报地址错 | `broker.conf` 中 `brokerIP1` 应为容器名 `rocketmq-broker`，不要写宿主 IP |
| 前端打开白屏 | 检查 nginx 容器：`docker logs jeepay-ui-manager`，多为后端 502 |
| 端口冲突 | 修改 `.env` 端口段，重启：`bash deploy/deploy.sh` |
| Redis 密码无效 | Redis 7 必须用 `requirepass`，确认 `.env` 与连接串一致 |
| 想完全重来 | `bash deploy/rollback.sh` 选 2（清空数据卷） |

## 十、安全建议（上线前必做）

> ⚠️ 测试通过后，**生产化之前**务必完成以下项目：

1. **改默认密码**：
   - 运营后台 `jeepay / jeepay123`
   - MySQL root
   - Redis 密码
2. **宝塔防火墙**：仅放通 80/443，关闭 22 公网入口，改走 VPN 或宝塔安全入口
3. **fail2ban**：安装并启用，防止暴力破解
4. **`.env` 严禁入库**：本项目已加 `.gitignore`，请勿手动 `git add -f`
5. **HTTPS**：拿到域名后，宝塔 → SSL → Let's Encrypt 一键签发
6. **数据库定期备份**：宝塔 → 计划任务 → 每日 mysqldump
7. **接管 Stripe live key 前**：webhook URL 切到 HTTPS 域名
8. **日志清理**：`./logs/` 与 `backup/` 占空间，配 logrotate 或定期清理
