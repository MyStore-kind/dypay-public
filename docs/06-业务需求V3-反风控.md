## 三、反风控核心需求（这是重点）

### 3.1 三方风控的本质（你必须理解的对手画像）

通道方（Stripe/PayPal/Alipay 等）的风控关注点：

| 维度 | 阈值参考 | 触发后果 |
|------|---------|---------|
| **拒付率（Chargeback Rate）** | >0.9%（Visa） >1%（Mastercard） | 加入 VAMP/EMP 监控名单 → 罚款 → 封号 |
| **投诉率（Dispute Rate）** | >1% | 限额、提高费率、要求保证金 |
| **退款率（Refund Rate）** | >5% | 警告、人工审核 |
| **成功率（Auth Rate）** | <85% | 怀疑欺诈测卡、降权 |
| **高风险 MCC** | 赌博/成人/虚拟物品 | 直接拒绝接入或封号 |
| **资金流动异常** | 集中地区 / 短时大额 | 冻结资金 |
| **设备/IP 特征** | 同设备多卡 / IP 黑名单 | 拒交易 |
| **3DS 比例** | 强制 SCA 区域不达标 | 拒交易 |

### 3.2 你需要确认的 7 个核心问题

#### 问题 1：商户类型与 MCC 行业（最关键）
你的商户主要做什么业务？

- [ ] **A. 低风险**：实物电商、SaaS、教育、订阅服务
- [ ] **B. 中风险**：虚拟商品、数字内容、游戏点卡、订阅会员
- [ ] **C. 高风险**：直播打赏、约会、博彩相关、加密货币
- [ ] **D. 混合**：____________

> 影响：决定通道选型、拒付率管控策略、是否需要拆单/分流

#### 问题 2：可接受的拒付率/投诉率阈值
- [ ] **A. 严格**：拒付率 < 0.5%，投诉率 < 0.7%（保守，安全）
- [ ] **B. 中等**：拒付率 < 0.8%，投诉率 < 0.9%（接近通道红线）
- [ ] **C. 激进**：超过红线接受换号（短期生命周期）

#### 问题 3：商户审查严格度
新商户接入时如何审核？
- [ ] **A. 严格 KYB**：营业执照、域名备案、客服信息、退款政策
- [ ] **B. 中等**：基本信息 + 网站快速审查
- [ ] **C. 宽松**：自助开通，事后监控
- [ ] **D. 分级**：高风险严格、低风险宽松

#### 问题 4：通道分配策略
当一个商户有多个通道可用时，如何分配？
- [ ] **A. 单通道独占**：每个商户绑定一个通道
- [ ] **B. 多通道轮询**：按比例分配（如 50% Stripe / 50% PayPal）
- [ ] **C. 智能路由**：根据风险评分、成功率、费率自动选择
- [ ] **D. 商户指定**：商户下单时指定通道

#### 问题 5：风险数据监控周期
风控数据多久统计一次？
- [ ] **A. 实时**（每笔订单后立即更新）
- [ ] **B. 准实时**（5 分钟聚合）
- [ ] **C. 小时级**
- [ ] **D. 日级**

#### 问题 6：超限处理方式
某商户拒付率即将超阈值时怎么处理？
- [ ] **A. 自动熔断**：暂停该商户支付
- [ ] **B. 限速降流**：降低交易速率
- [ ] **C. 切换通道**：自动切到备用通道
- [ ] **D. 仅告警**：人工介入

#### 问题 7：通道账号管理
每个通道（Stripe/PayPal）持有多少账号？
- [ ] **A. 单账号**：所有商户共用
- [ ] **B. 商户独立账号**：每商户一个通道账号
- [ ] **C. 账号池**：多账号轮换使用（反风控常用）
- [ ] **D. 分组账号**：按行业/风险等级分组

## 五、反风控的技术手段（我建议你做）

### 5.1 通道侧
- **多账号池**：每个通道维护多个账号，按健康度路由
- **流量稀释**：单账号日交易控制在阈值内
- **业务隔离**：高风险/低风险商户用不同账号
- **拒付预警**：拒付率接近红线时主动降流

### 5.2 商户侧
- **进件审核**：KYB 资料、网站爬虫审查、域名年龄
- **行为评分**：根据历史数据动态调整商户风险评级
- **限额管理**：单笔/日/月限额按风险等级配置
- **熔断机制**：超限自动暂停

### 5.3 订单侧
- **拒付预测**：基于规则/ML 提前拦截高风险订单
- **3DS 智能触发**：高风险订单强制 3DS
- **黑名单**：卡号/IP/邮箱/设备指纹
- **频次控制**：同卡/同IP 短时多笔拦截

### 5.4 数据侧
- **实时监控**：成功率/拒付率/投诉率实时计算
- **多维聚合**：按通道/商户/MCC/地区/时间维度
- **告警通知**：超阈值企微/邮件/短信
- **拒付证据库**：方便商户应对 Chargeback
