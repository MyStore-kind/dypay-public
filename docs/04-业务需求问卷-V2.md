- 强调"国际" → 跨境收款、多币种
- 提到"代理商"（前面阶段 1 我已实现） → 有渠道分销需求

**我推断你的商业模式是**：

```
你的定位：跨境收单服务商（Cross-border PSP）

业务链路：
  海外消费者
       ↓ 信用卡/电子钱包支付
   你的支付网关（基于 JeePay 改造）
       ↓ 对接国际通道
   Stripe / PayPal / Adyen 等
       ↓ 资金清算
   你的境外结算账户
       ↓ 扣除手续费 + 代理商分润
   商户结算账户（多币种或换汇为本币）

收入来源：
  1. 商户手续费差价（向商户收 3.5% + 通道实际成本 2.9% = 你赚 0.6%）
  2. 汇率差（换汇时加点 0.3% - 0.5%）
  3. 提现/结算手续费

目标客户：
  - 中国跨境电商卖家（独立站、Shopify 卖家）
  - 海外 SaaS 订阅服务
  - 数字内容/游戏出海开发者
  - 跨境贸易企业

渠道策略：
  - 通过代理商发展商户（前面我已实现 3 级代理商体系）
  - 代理商获取分润，激励拉新
```

## 四、风险与合规提示

### 4.1 你必须了解的法律风险

> ⚠️ **重要**：以下场景在中国大陆属于违规，请确认你不涉及：

- ❌ 未持牌从事支付业务（央行处罚）
- ❌ 二清（无牌商户挂靠平台收款再分账）
- ❌ 跨境换汇（绕过外管局额度）
- ❌ 为非法网站收款（赌博、色情、洗钱）

> ✅ **合法路径**：
>
> 1. 在境外注册主体（香港/新加坡/美国/英国）
> 2. 申请当地支付牌照（HK MSO / SG MAS / US MSB / UK FCA）
> 3. 或使用 Stripe Connect 模式（你做 Platform，商户做 Connected Account，由 Stripe 持牌）
> 4. 跨境结汇必须通过持牌机构（如 PingPong、Airwallex）
