## 十、常见问题 FAQ

**Q1：风控钩子异常会阻断下单吗？**
不会。OrderRiskHookService 内部 try-catch，异常时降级为 ALLOW 并写告警日志，保证下单不受影响。

**Q2：拒付 Webhook 重复推送如何幂等？**
ChargebackService.onChargebackEvent() 内按 `event_id + dispute_id` 做唯一约束插入，重复事件直接忽略。

**Q3：汇率源全挂时退款怎么算？**
退款强制使用 PayOrder.frozen_rate（订单创建时锁定的汇率），与实时汇率源解耦，永不失败。

**Q4：代理商分润中途被冻结？**
AgentProfitSettleSchedule 检查 agent.state=2 时将记录置为 state=2（已冻结），不进入结算，同时触发告警。

**Q5：23 项默认阈值在哪改？**
运营后台 → 风控阈值配置（`/risk/threshold`），或直接改 `t_risk_threshold_config` 表，无需重启。

**Q6：上线前最少要配置哪些环境变量？**
必填：`STRIPE_WEBHOOK_SECRET` / `PAYPAL_WEBHOOK_ID` / DB / Redis 连接。可选：`FIXER_API_KEY`（不配则汇率仅手动）、`TELEGRAM_BOT_TOKEN`（不配则告警仅邮件）。

**Q7：如何紧急关闭整套风控？**
`risk.enabled=false` 重启 manager；或在 sys_config 表 UPDATE `risk_control_enabled='false'` + 调用 `/api/sys/config/refresh` 刷新缓存（秒级生效）。

**Q8：前端菜单不显示怎么排查？**
检查：① `permission_menu_patch.sql` 是否已执行；② 用户角色是否绑定新 entId；③ `appConfig.js#asyncRouteDefine` 是否注册了对应 componentName；④ 浏览器 DevTools 看 `/api/currentUser/getCurrentMenus` 返回。
